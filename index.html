Calibration

Turn device volume fully up and leave it there. Choose your method, play the 1 kHz tone (or, for sound field, the calibration noise), set the level by your chosen method, then stop and enter the value(s). That becomes the reference; presentation level is set with the slider below.



    Set each audiometer channel's dial and zero it to VU 0 off the tone. Give an ear more headroom (a higher dial) if its loss needs it — the software uses each side's dial for that ear.

    WUDR (two-phase)

    Defaults: down −4.76% / up +8.33% (working); down −11.1% / up +20.8% (initial). 0 reversals = single-phase.

    Noise (SNR)

    WUDR steps = quiet-mode dB steps × the multiplier. Noise (noise.mp3) is fixed at the presentation level; the signal moves by the SNR. Noise starts lead ms before the word’s audible onset and ends trail ms after it, ramping in/out. “Word onset in file” is the silent lead-in inside each stimulus file — adjust so the noise lines up with the actual speech.

    Verify low-pass filter

    Frequency response of the exact filter applied to the stimuli (10th-order Butterworth, built at 48 kHz — the sound-file rate). The smooth line is the analytic response of the filter coefficients; the dots are measured by passing white noise through the identical filter code and averaging. Unfiltered = 0 dB; the dashed marker shows the −3 dB point at the corner frequency.
